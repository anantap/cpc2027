    Tot de start van de 10K-opbouw houd je de basis vast: elke week hetzelfde, niets erbij. Voelt het zwaar, loop dan de lange run ook 5 km. Vanaf 9 november sluit je run 1 af met 4 korte versnellingen: ontspannen hard, niet sprinten, op een vlakke, zachte ondergrond. Speelt je scheenbeen op, laat ze dan weg.
    Run 1 is elke week een vaste, rustige 5 km. Run 2 is een rustige 5 km op praattempo. Run 3 is de lange duurloop die stap voor stap oploopt. Elke 3–4 weken een cutback-week: de lange duurloop gaat terug zodat je lichaam kan herstellen.

    Vuistregels
    • Tempo: praat-test; kun je niet meer kletsen, dan ga je te snel. Interval- en tempodagen zijn bewust sneller.
    • Herstel: rustdag tussen elke run; warming-up vóór elke run.
    • Opbouw: nooit meer dan ~10% afstand erbij per week.
    • Flexibel: lukt een week niet, herhaal 'm — er is ruim tijd tot de CPC.
    • Pijn: stijf is oké; scherpe pijn = rust nemen, niet doorlopen.
